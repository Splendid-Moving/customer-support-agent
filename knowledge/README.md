# Knowledge base

Everything the agent is allowed to say about us lives in this folder. If a fact
isn't in here, the agent tells the customer it doesn't know and offers to have
someone from the office follow up — it will **not** guess.

## How to change what the agent knows

Almost everything here is generated from one spreadsheet:

**`source/splendid_moving_kb.xlsx`**

1. Edit the spreadsheet — add a row, fix an answer, update `last_verified`
2. Run `python scripts/import_kb.py`
3. Commit both the spreadsheet and the regenerated `.md` files

The `.md` files with a `generated by` line at the top are **overwritten** on
every import, so don't edit those by hand — your change would vanish on the next
run.

### Why not read the spreadsheet directly?

Because then nobody can review a change. A spreadsheet is a binary file: a commit
that quietly changes the hourly rate shows up in git as "the file changed" and
nothing else. Going through markdown means a rate change looks like a rate change
in the diff, and somebody can catch it before customers hear it.

## The columns

| Column | What it's for |
|---|---|
| `id` | Unique, e.g. `R01`. The import fails on duplicates. |
| `category` | Becomes the filename — all `Rates` rows land in `rates.md`. |
| `question` | Phrase it the way a customer would ask, not the way we'd file it. |
| `answer` | **Said to customers close to verbatim.** Write it as we'd want it read aloud. |
| `notes` | Internal. How to handle the topic — "ask how many movers first", "escalate the exact amount". The agent follows these but never repeats them. |
| `last_verified` | When someone last confirmed it's still true. |

Write `notes` containing the word **confirm** for anything unresolved — the
importer prints those at the end so they don't get published by accident.

## Hand-written files

`company.md` is **not** generated. It holds background the spreadsheet doesn't
cover (hours, service area, what comes with the crew), taken from
`main_website/BRAND_INFO.md`. If any of it ever gets answered in the spreadsheet,
delete it from `company.md` — two sources for one fact is how the agent ends up
contradicting itself depending on which question got asked.

## How to write a good answer

- **Facts, not marketing.** "3-hour minimum, billed in 15-minute increments after
  that" is useful. "We pride ourselves on excellence" gets repeated verbatim and
  sounds like a brochure.
- **Say the awkward things too.** Parking tickets, plants, what happens if it
  doesn't all fit. Half of what customers ask about is the limits, and if the
  answer isn't here the agent has to punt to a human.
- **Numbers exactly as you want them repeated.** The agent quotes them verbatim
  and is blocked from doing arithmetic on them — it cannot turn an hourly rate
  into a total.
